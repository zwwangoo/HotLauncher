# HotLauncher 需求文档

> 一个 macOS 菜单栏小工具：按全局快捷键，启动或切换到指定应用。仅自用。

## 1. 目标与范围

**目标**：在任何界面按下预设快捷键，立即启动或切换到对应应用。

**范围内**
- 快捷键 → 应用的绑定（多条）
- 菜单栏常驻、设置窗口
- 开机自启

**范围外（明确不做）**
- 搜索面板（Alfred / Raycast 式）
- 窗口管理、剪贴板、脚本、插件等其他功能
- 分发、公证、自动更新

## 2. 运行环境

| 项 | 要求 |
|---|---|
| 系统 | macOS 14 (Sonoma) 及以上 |
| 语言 | Swift 6.x，SwiftUI + AppKit |
| 构建 | **`swiftc` + Command Line Tools，不依赖 Xcode**（不用 SwiftPM，原因见 README） |
| 第三方依赖 | 无。快捷键用 Carbon `RegisterEventHotKey` 自行封装 |
| 架构 | 仅 arm64（Apple Silicon） |
| 签名 | 本地 ad-hoc 签名（`codesign -s -`），内部分发，不公证 |

## 3. 功能需求

### F1 全局快捷键注册
- 使用 `RegisterEventHotKey`，不申请辅助功能和输入监控权限。
- 支持「修饰键 + 普通键」组合，必须包含 ⌘ ⌥ ⌃ 之一（仅 ⇧ 会吞掉正常输入，禁止）。
- 绑定变更后即时生效，不需要重启。
- 同一快捷键只能绑定一个应用，重复绑定时提示并拒绝保存。
- 只能拒绝系统保留组合和本应用内的重复绑定。macOS 允许不同进程重复注册同一个 Carbon 热键，
  因此与**其他应用**的冲突无法检测，也就不做“注册失败”提示。

### F2 启动或切换应用
按下快捷键时：

| 目标应用状态 | 行为 |
|---|---|
| 未运行 | 启动并置前 |
| 运行中，不在前台 | 激活到前台 |
| 运行中，已在前台 | 默认不处理；可选「再次按下隐藏」 |
| 找不到（已卸载或移动） | 提示音，设置里该行标红 |

- 应用以 **Bundle ID** 为主标识，同时记录路径作为兜底。
- 激活应用使用 `NSRunningApplication.activate`；启动使用 `NSWorkspace.openApplication`。

### F3 绑定管理（设置窗口）
- 列表显示：应用图标、应用名、快捷键、启用开关。
- 添加：点「+」，通过 `NSOpenPanel` 选择 `.app`（默认目录 `/Applications`），也支持拖入 `.app`。
- 录制快捷键：点击快捷键框，进入录制状态，按下组合键即录入；`Esc` 取消，`⌫` 清除。
- 删除、启用/停用单条绑定。
- 每条绑定可选「再次按下时隐藏」（默认关）。

### F4 菜单栏常驻
- `LSUIElement = YES`，不显示 Dock 图标。
- 使用 `MenuBarExtra`，菜单项：
  - 绑定列表（只读，显示快捷键，点击也可启动）
  - 暂停/恢复全部快捷键
  - 设置…
  - 开机自启（勾选）
  - 退出

### F5 开机自启
- 使用 `SMAppService.mainApp`，在菜单中开关，状态以系统实际值为准。

### F6 配置持久化
- 路径：`~/Library/Application Support/HotLauncher/config.json`。
- 内容：绑定列表（bundleID、路径、keyCode、modifiers、启用、再次按下隐藏）和全局暂停状态。
- 启动时读取，文件损坏时备份为 `config.json.bak` 并使用空配置。
- 手改 JSON 后不要求热加载。

## 4. 非功能需求

| 项 | 指标 |
|---|---|
| 响应 | 按键到应用置前 < 200ms（应用已运行时） |
| 资源 | 空闲 CPU ≈ 0%；常驻内存目标 < 50MB（实测约 83MB，SwiftUI + MenuBarExtra 的基线，暂不优化） |
| 稳定 | 单实例运行，重复启动时直接退出 |
| 权限 | 不弹出任何系统权限请求 |
| 体积 | `.app` < 5MB |

## 5. 技术方案

### 5.1 目录结构
```
HotLauncher/
├── Sources/HotLauncher/
│   ├── HotLauncherApp.swift     # @main, MenuBarExtra, Settings 窗口
│   ├── HotKeyCenter.swift       # Carbon 注册/注销/事件分发
│   ├── AppLauncher.swift        # 启动/激活/隐藏逻辑
│   ├── Binding.swift            # 数据模型 (Codable)
│   ├── ConfigStore.swift        # JSON 读写，ObservableObject
│   ├── ShortcutRecorder.swift   # 快捷键录制控件
│   └── SettingsView.swift
├── Resources/Info.plist         # LSUIElement、Bundle ID、最低系统版本
├── Resources/AppIcon.icns       # 应用图标（由 scripts/make-icon.sh 生成并提交）
└── scripts/                     # build.sh 构建 / package.sh 打 DMG / make-icon.sh 生成图标 / swift-env.sh 公共编译参数
```

### 5.2 构建流程（无 Xcode）
1. `swiftc -O` 直接编译 `Sources/HotLauncher/*.swift`
2. 脚本组装 `build/HotLauncher.app/Contents/{MacOS,Resources,Info.plist}`
3. `codesign --force --deep -s -` ad-hoc 签名
4. `scripts/build.sh --install` 复制到 `/Applications`

### 5.3 关键实现点
- `HotKeyCenter`：`InstallEventHandler` 只装一次，用 id 映射到绑定；变更时先 `UnregisterEventHotKey` 再重新注册。
- 快捷键录制：用 `NSEvent.addLocalMonitorForEvents(.keyDown)`，只在自己窗口获得焦点时生效，不需要权限。
- 避免系统保留键：录制时拒绝 `⌘Space`、`⌘Tab`、`⌘Q` 等，并给出提示。
- 菜单栏应用打开设置窗口时，需要临时切换 `NSApp.setActivationPolicy(.regular)` 才能拿到焦点，关闭后切回 `.accessory`。

## 6. 验收标准

1. 无 Xcode 环境下，执行 `scripts/build.sh` 可生成可运行的 `HotLauncher.app`。
2. 添加绑定「⌥1 → Safari」后：Safari 未运行时按键会启动它；已运行时会切到前台。
3. 开启「再次按下隐藏」后，Safari 在前台时再按一次会隐藏它。
4. 重复绑定同一快捷键会被拒绝并提示。
5. 删除、停用绑定后快捷键立即失效。
6. 退出后重新打开，绑定仍在。
7. 开机自启开关与「系统设置 → 登录项」状态一致。
8. 整个使用过程不出现系统权限弹窗，Dock 无图标。

## 7. 里程碑
